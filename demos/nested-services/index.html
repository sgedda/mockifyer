💡 What's Happening?

This demo shows nested service calls with Mockifyer:

  • The frontend calls the Gateway service
  • Gateway calls Weather API → Places API → Currency API
  • All requests share the same x-mockifyer-request-id
  • The Dashboard shows the complete trace with all 3 hops
  • Each recorded request can be copied as a curl command
  • Scenarios let you test different states (empty data, errors, etc.)
